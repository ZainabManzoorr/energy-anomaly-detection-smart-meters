 VoltSense – Smart Energy Analytics & Anomaly Detection

VoltSense is an end-to-end energy analytics and anomaly detection system that analyzes multi-house smart meter data to uncover consumption patterns, detect abnormal usage, and generate actionable insights using statistical methods and machine learning.

It includes a Streamlit dashboard for interactive visualization and storytelling.

 Live Demo

https://voltsense.streamlit.app/

Features
Multi-house energy data processing
Time-series feature engineering
 Daily & hourly energy trends
House-wise consumption comparison
Weekend vs weekday analysis
 Hybrid anomaly detection:
Z-score statistical detection
Spike-based rule detection
Machine Learning (Isolation Forest)
Pre-generated visualization dashboard (Streamlit)
Automated energy insights
Streamlit Dashboard

The dashboard includes:

KPI overview (records, houses, days)
Daily energy trends
Hourly usage patterns
House comparison charts
Weekend vs weekday behavior
Anomaly detection visualization
